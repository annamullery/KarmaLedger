# KarmaLedger

KarmaLedger is a distributed, real-time data management platform that integrates blockchain and smart contract technologies.

KarmaLedger is aimed at developers who need a straightforward, dependable solution.

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/KarmaLedger.git`
2. `cd KarmaLedger`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
